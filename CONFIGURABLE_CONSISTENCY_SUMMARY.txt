New Configuration Property:
  Property: lms-cassandra.consistency.level
  Type: String
  Default: LOCAL_QUORUM
  Optional: Yes (will default if not specified)

Example in application.conf:
  lms-cassandra {
    host = "cassandra-host"
    port = 9042
    consistency.level = "LOCAL_QUORUM"  # Can be: QUORUM, LOCAL_QUORUM, LOCAL_ONE, ONE, ALL, ANY
  }

Helper Method (ActivityAggregatesFunctionV2.scala):
────────────────────────────────────────────────────

private def applyConsistencyLevel(stmt: com.datastax.driver.core.Statement): com.datastax.driver.core.Statement = {
  try {
    val consistencyLevel = ConsistencyLevel.valueOf(config.dbConsistencyLevel.toUpperCase)
    stmt.setConsistencyLevel(consistencyLevel)
  } catch {
    case ex: IllegalArgumentException =>
      logger.warn(s"Invalid consistency level '${config.dbConsistencyLevel}', defaulting to LOCAL_QUORUM")
      stmt.setConsistencyLevel(ConsistencyLevel.LOCAL_QUORUM)
  }
  stmt
}

================================================================================
CONSISTENCY LEVEL OPTIONS
================================================================================

Level          Speed    Durability  What It Does
─────────────────────────────────────────────────────────────────────────────
LOCAL_QUORUM   Medium   ✅ High     Majority of nodes in local DC (RECOMMENDED)
QUORUM         Slower   ✅✅ V.High Full cluster majority
LOCAL_ONE      Fast     ⚠️ Medium   Single node in local DC (eventual consistency)
ONE            Fastest  ❌ Low      Single node (no replication guarantee)
ALL            Slowest  ✅✅✅ Max  All nodes must acknowledge
ANY            Fast     ⚠️ Low      Write-only operations

RECOMMENDED: LOCAL_QUORUM (balance of consistency and performance)

================================================================================
ERROR HANDLING
================================================================================

Invalid Consistency Level:
  If user specifies invalid consistency level (e.g., "INVALID_LEVEL"):

  1. Log WARNING: "Invalid consistency level 'INVALID_LEVEL', defaulting..."
  2. Fall back to LOCAL_QUORUM automatically
  3. Application continues to function safely

Example:
  lms-cassandra.consistency.level = "SUPER_STRONG"

  Result:
  [WARN] Invalid consistency level 'SUPER_STRONG', defaulting to LOCAL_QUORUM
